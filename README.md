# Meet Pace

Веб-приложение для ручного управления списком участников и таймером выступлений.

## Быстрый запуск

Установите Node.js, откройте терминал в папке проекта и запустите:

```powershell
node serve.mjs
```

Затем откройте `http://localhost:4173`.

Введите имя в верхней форме и нажмите «Добавить». Участники сохраняются локально в браузере.

## Жеребьёвка заданий

Кнопка «Выбрать участника» назначает случайному участнику случайное задание на следующий звонок. Внутри одного круга каждый участник выбирается только один раз. Когда задания получили все участники, начинается новый круг. Прогресс круга и общий лог сохраняются в браузере.

Отдельная жеребьёвка «На этом звонке» выдаёт лёгкие импровизационные задания во время текущего разговора. Для неё ведётся независимый круг участников по тем же правилам. Результаты также сохраняются в общем логе.

## Текущая логика таймера

Начало выступления фиксируется вручную кнопкой «Начать» напротив участника. Одновременно может идти одно выступление.

После окончания установленного времени таймер продолжает считать перерасход в формате `+00:01`. Выступления дольше лимита выделяются красным в логе действий.

Интерфейс доступен на английском и русском языках. Переключатель EN/RU находится в верхней панели, выбор сохраняется в браузере.
