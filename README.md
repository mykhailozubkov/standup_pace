# Meet Pace

Веб-приложение для ручного управления списком участников и таймером выступлений.

## Быстрый запуск

Установите Node.js и создайте API-ключ на странице [OpenRouter Keys](https://openrouter.ai/settings/keys).

Скопируйте `.env.example` в `.env` и вставьте ключ вместо значения-заглушки. Затем откройте терминал в папке проекта и запустите:

```powershell
node --env-file=.env serve.mjs
```

Затем откройте `http://localhost:4173`.

Введите имя в верхней форме и нажмите «Добавить». Участники сохраняются локально в браузере.

## Жеребьёвка заданий

Кнопка «Выбрать участника» назначает случайному участнику сгенерированное моделью задание на следующий звонок. Внутри одного круга каждый участник выбирается только один раз. Когда задания получили все участники, начинается новый круг. Прогресс круга и общий лог сохраняются в браузере.

Отдельная жеребьёвка «На этом звонке» генерирует лёгкие импровизационные задания во время текущего разговора. Для неё ведётся независимый круг участников по тем же правилам. Результаты также сохраняются в общем логе.

Задания генерируются бесплатной моделью `dots-studio/dots-3-note-preview:free`. Последние задания передаются модели как список исключений, чтобы уменьшить количество повторов. Ключ используется только сервером и не попадает в браузер или `localStorage`.

При необходимости модель можно заменить через переменную `OPENROUTER_MODEL` в `.env`.

## Обработка ошибок

Приложение различает ошибки локального сервера, сети и OpenRouter: неверный или отсутствующий ключ, ограничения аккаунта, запрет доступа, блокировку контента, отсутствующую модель, лимит запросов, тайм-аут, перегрузку и недоступность провайдера, внутренние ошибки OpenRouter, некорректный ответ модели и ошибки формата локального запроса. Для временных ошибок сервер делает до трёх попыток. Каждый ответ с ошибкой содержит безопасный `requestId` для диагностики без публикации API-ключа.

Проверить таблицу ошибок можно командой:

```powershell
node --test tests/errors.test.mjs
```

> Важно: открывайте приложение через `http://localhost:4173`, а не напрямую через `index.html`. GitHub Pages не умеет выполнять `serve.mjs`; для публичной версии понадобится серверный или serverless-хостинг.

## Текущая логика таймера

Начало выступления фиксируется вручную кнопкой «Начать» напротив участника. Одновременно может идти одно выступление.

После окончания установленного времени таймер продолжает считать перерасход в формате `+00:01`. Выступления дольше лимита выделяются красным в логе действий.

Интерфейс доступен на английском и русском языках. Переключатель EN/RU находится в верхней панели, выбор сохраняется в браузере.
